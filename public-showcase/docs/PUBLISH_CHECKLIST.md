# Publish Checklist (Docs-Only Repo)

## Before First Push

- Confirm this repo contains docs/media only.
- Confirm no source/runtime implementation files are included.
- Confirm no API tokens, OAuth secrets, or private URLs appear in docs or media.
- Confirm screenshots do not expose sensitive data.

## Repo Setup Steps

1. Create a new public GitHub repository (for example: `void-sovereign-showcase`).
2. Copy contents of this folder into that repository root.
3. Commit and push.
4. Enable repository description and homepage link.
5. Pin repository on your GitHub profile.
