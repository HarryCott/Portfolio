# VOID SOVEREIGN (Public Showcase)

A real-time Twitch and OBS overlay platform that turns live stream events into cinematic, themed moments.

This repository is intentionally documentation-only.
Implementation source remains private.

## Why This Project Stands Out

- Real-time event orchestration across Twitch, OBS, dashboard commands, and music context
- Queue-based visual/audio sequencing for deterministic live behavior
- Scene-aware stream logic (Starting Soon, Gameplay, BRB, Stream Ending)
- Runtime telemetry loop for live state observability
- Reliability patterns with integration fallbacks (TTS providers, OBS control paths, Twitch auth handling)

## What It Demonstrates

- Frontend systems engineering under live constraints
- Integration design (third-party APIs + operational tooling)
- Product-level thinking: operator controls, resilience, and audience experience
- Modular architecture for maintainability and rapid iteration

## Project Snapshot

- Stack: HTML, CSS, JavaScript, PHP relay endpoints
- Integrations: ComfyJS, OBS APIs/WebSocket, Spotify API, browser audio/TTS
- Core capability: Transform high-volume live events into branded, coherent visual narratives
