# Media Folder Guide

Use this folder for portfolio-safe assets that demonstrate outcomes without exposing implementation details.

## Recommended Assets

- `demo-01-scene-flow.mp4`: Starting Soon -> Gameplay -> BRB transition
- `demo-02-alerts.mp4`: follow/sub/raid/cheer sequence
- `demo-03-dashboard-control.mp4`: dashboard command to live overlay effect
- `screenshot-dashboard.png`: control panel UI
- `screenshot-overlay-gameplay.png`: gameplay scene overlay
- `screenshot-overlay-brb.png`: BRB/AFK state

## Capture Tips

- Keep clips 20-60 seconds each.
- Show one capability per clip.
- Crop or blur any private URLs, IDs, or tokens.
- Avoid recording source code in demonstrations.

## File Size Guidance

- Prefer H.264 MP4 for compatibility.
- Target < 30 MB per clip for fast portfolio loading.
